# Three of these pins are load-bearing, not arbitrary:
#
#   scikit-learn==1.9.0 -- the .joblib models were pickled by 1.9.0. A different

#     possibly producing invalid results.
#
#   numpy==2.4.6 -- two constraints squeeze it from both sides.
#     feature_engineering.py calls np.trapezoid, which does not exist before
#     numpy 2.0. And shap depends on numba, whose newest release supports numpy
#     up to 2.4; ask for 2.5 and pip backtracks to a 2023 numba source tarball
#     that refuses to build on Python 3.12. 2.4.6 satisfies both.
#
#   numba / llvmlite -- pinned only so the resolver cannot wander again.
